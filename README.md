# Lumina RPG

Prototipo de RPG em Python com Ursina e Panda3D.

## Estado atual
O main.py ainda e o prototipo inicial. Os testes de personagem, PBR e espada estao em scripts separados.
Os seis modelos glTF selecionados ficam em assets/models/characters.
Consulte HISTORICO_DO_PROJETO_LUMINA_RPG.txt para o historico e as proximas etapas.

## Dependencias
Python 3.12, Ursina, Panda3D, panda3d-gltf e panda3d-simplepbr.
Instale com: python -m pip install -r requirements.txt

## Modelos
LowPoly Models by Quaternius, sob CC0 1.0. Licenca em assets/models/characters/LICENSE-CC0.txt.
